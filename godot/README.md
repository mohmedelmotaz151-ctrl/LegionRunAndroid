# Legion Run 3D — Godot 4

A self-contained 3D crowd-runner prototype built with Godot 4 and procedural 3D meshes (no external art assets required).

## Open the project
1. Install Godot 4.4 or newer.
2. Import `godot/project.godot` from the Godot Project Manager.
3. Press F6/F5 or the Play button.

## Current prototype
- Perspective 3D road, lighting, camera and HUD.
- Procedurally assembled 3D squad characters.
- Swipe or arrow-key lane switching.
- Add/multiply gates, hazards, squad growth and a finish encounter.
- No network connection or paid assets required.

## Status
This is the first playable 3D foundation. It is not yet a final production game. Android/iOS export presets, optimized character animation, sound, polished environments and expanded level design are follow-up work.
